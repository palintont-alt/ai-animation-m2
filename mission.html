โจทย์

สร้าง Animation ในหัวข้อ “AI กับชีวิตประจำวัน” หรือหัวข้อที่ครูกำหนด โดยใช้กระบวนการตั้งแต่แนวคิด → ตัวละคร → Prompt → Storyboard → Animation → ตัดต่อ

📋 ขั้นตอนการทำงาน

  1. กำหนดชื่อเรื่องและสาระสำคัญ
  2. ออกแบบตัวละครอย่างน้อย 1 ตัว
  3. สร้าง Prompt สำหรับภาพและการเคลื่อนไหว
  4. ทำ Storyboard อย่างน้อย 4 ฉาก
  5. สร้างคลิปและตัดต่อเป็นเรื่องเดียว
  6. ตรวจสอบลิขสิทธิ์ ความถูกต้อง และความเหมาะสม
