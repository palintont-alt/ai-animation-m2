บทเรียนการสร้างอนิเมชันด้วย AI

01

🎞️ รู้จัก Animation

Animation คือการทำให้ภาพนิ่งหลายภาพแสดงต่อเนื่องจนผู้ชมรู้สึกว่าเกิดการเคลื่อนไหว

หลักคิด: การเปลี่ยนแปลงทีละน้อย + ลำดับเวลา = การเคลื่อนไหว

กิจกรรม

ลองสังเกต Animation ที่ชอบ แล้วบอกว่า “ตัวละครเคลื่อนไหวอะไร” และ “กล้องเคลื่อนอย่างไร”

02

🤖 Generative AI

AI เชิงสร้างสรรค์สามารถช่วยสร้างข้อความ ภาพ เสียง และวิดีโอจากคำสั่งของเรา

Text → Image
ข้อความ → ภาพ
Image → Video
ภาพ → วิดีโอ
Text → Video
ข้อความ → วิดีโอ
Text → Audio
ข้อความ → เสียง
03

🎭 ออกแบบตัวละคร

กำหนดชื่อ อายุ บุคลิก เสื้อผ้า สี รูปร่าง และจุดเด่น เพื่อให้ AI สร้างตัวละครได้ตรงกันหลายฉาก

  • Character name
  • Appearance
  • Personality
  • Costume & color
  • Signature feature
04

✍️ Prompt Engineering

Prompt คือคำสั่งที่ใช้สื่อสารกับ AI ยิ่งระบุรายละเอียดสำคัญชัดเจน ผลลัพธ์ยิ่งควบคุมได้ง่าย

ตัวละคร + การกระทำ + สถานที่ + มุมกล้อง + แสง + สไตล์
เปิด Prompt Lab →
05

🎬 สร้าง Animation ด้วย AI

  1. สร้างภาพตัวละครและฉาก
  2. กำหนด Motion เช่น เดิน วิ่ง หันหน้า
  3. กำหนด Camera movement เช่น pan / zoom
  4. สร้างคลิปและตรวจสอบความต่อเนื่อง
  5. นำคลิปมาตัดต่อและใส่เสียง
06

📝 Storyboard

Storyboard ช่วยวางภาพและลำดับเรื่องก่อนสร้างจริง ทำให้ทีมทำงานง่ายและลดการลองผิดลองถูก
